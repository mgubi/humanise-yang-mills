This plan adapts the 32 source clusters developed in Scott Armstrong's Yang-Mills informalization project into mathematical work packages for this monograph. The compiled-Lean source map was inspected at commit 8f3c7ccaeabb17b0f928bc1a2e75328691de3032; see the 32-cluster disposition and evidence. The IDs below are temporary planning labels. Canonical YM-<issue> IDs are created only when bounded GitHub issues exist.

One row should normally become one explanation issue, except where a literature task resolves the result or the split notes require finer interfaces. Dependencies are conceptual and provisional; they are not a claim about every Lean constant edge.

Recommended first wave

Open these bounded tasks before distributing the large RG units:

  1. Build and axiom audit. Reproduce the pinned build, regenerate the usage inventories, and run supported transitive axiom checks for all 17 roots.

  2. Public statement audit. Check the external statement.md line by line against the elaborated public definitions and record the exact theorem scope.

  3. External-map synchronization. Use the pinned compiled-Lean map and its 32-cluster disposition; link current unit outlines and key statements from task issues without copying generated TSVs.

  4. Literature searches. Start with SU(2) simplicity, OS reconstruction, Gaussian/cluster expansion tools, and standard limit/compactness results.

  5. Two pilot units. Use PU-28 (SU(2)) and CP-03 (the effective-coupling asymptotic) to calibrate citation, source-correspondence, and review standards.

  6. Main-spine interface audit. Trace the exact handoff from PU-15 through PU-19 before assigning the very large nonlinear RG proof units.

Only after those tasks settle the interfaces should coordinators create canonical unit directories and distribute PU-08–PU-12 among several writers.

Known limitations of this pass

  • No Lean build, proof replay, or axiom audit was performed here.

  • The external map is same-revision and now derived from compiled Lean. All 32 pages have AI-written outlines at differing stages, with open points. Their checked or edited labels do not substitute for this project's independent correspondence and mathematical reviews.

  • No literature match has yet been independently accepted in blueprint/background/.

  • The splits inside III.4, III.10, and III.11 are mathematical recommendations; their exact statement interfaces and overlap with other packages remain tasks for the next audit. The compiled graph corrects source-unit links but does not determine a topological expository order.

  • The allocation includes alternative constructions. In particular, III.13's common family is not identified with the family of the public run in III.14.

  • The final dependency closure of YangMills.jointExistence must be distinguished from the union of all 17 release-root closures.
