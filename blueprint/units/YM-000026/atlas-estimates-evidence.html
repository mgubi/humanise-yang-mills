Mathematical proof notes

  1. For a fixed input point, the row sum is reindexed by \(z = y - \rho_L (x)\). The centered lift has one coordinate of magnitude at most \((L - 1) / 2\), so \(| \ell_L (r) |_1 / L \leqslant 2\); the difference from the source's \(+ 4\) margin is harmless. The same substitution on a fixed output column first decomposes each input uniquely as \(x = \ell_L (r) + Lv\); summing over \(v\) costs the original strip bound, then summing over residues contributes exactly \(L^4\). The one-step difference is exactly installation of forwardC, requiring the odd centered-lift carry identity.

  2. The sandwich proof uses \(d_L (x, y) \leqslant d_L (x + u, y + v) + |u|_1 / L + |v|_1\), absorbs each displacement in its stencil strip using both \(\sigma / L \leqslant \alpha\) and \(\sigma \leqslant \alpha\), and sums over the two intermediate face-label sets. The input difference is obtained by subtracting the two convolution formulas with the same summation variables; the difference acts on the installed tower kernel at the shifted inner input point, with no reindexing of the first displacement.

  3. The publication proof is therefore not blocked at Rack.legs: the local tower cross-kernel receipt is actually generated from the wire entrywise Pay estimate. The high-level public selection uses that proved route via the stored horizon plan, although this audit does not audit every other component of the selection theorem.
