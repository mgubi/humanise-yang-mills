  1. Bare coefficient [S]. YM.RG.History.Selected.starts (History.lean:237): ∀ N p, (A.rep N p N).v = 0 ∧ (A.rep N p N).eval = bare (A.β N p N); bare resolves to YM.Wilson.bare (open Wilson at History.lean:40). YM.Wilson.bare β U = Real.exp (−β * energy U) (Law.lean:58); YM.Wilson.energy U = Σ_{p : Face (Per n)} G.price (faceValue U p) (Law.lean:29); YM.Gauge.price u = 1 − (G.mat u).trace.re / G.repDim (MatrixGroup.lean:112). So at stage m = N the represented density equals exp(−β_{N,p,N} Σ_p (1 − r_G^{-1} Re tr U_p)), and β_{N,p,N} is the multiplier of that energy, as the correspondence says; its description of Rep.eval as "an exponential times an activity gas", not an action, is accurate. The closing remark of the section is justified by starts (second conjunct), with the normalisation spelled out in the correspondence.   3. Representation and Lie algebra [S]. YM.Gauge (MatrixGroup.lean:23–26): n : ℕ and a closed subgroup of Matrix.unitaryGroup (Fin (n+1)) ℂ; repDim = n + 1, dimPos : 0 < repDim (:73–75), so r_G ≥ 1 is exactly dimPos. YM.Gauge.Generates X := ∀ t : ℝ, exp (t • X) ∈ range G.mat (Lie.lean:26), YM.Gauge.lie the real submodule with this carrier (:126–135), generates_skew : star X = −X (:42–44), bracket_mem : X*Y − Y*X ∈ G.lie (:159–176). These support the text's derivative argument and its (implicit) use of bracket closure; the conventions agree with Hall, Definition 3.13 and Theorem 3.16 (checked against the versioned PDF, see the mathematics report).

  4. Simplicity [S]. YM.Gauge.Simple (Lie.lean:178–182): some X, Y ∈ G.lie with XY − YX ≠ 0, and every real submodule I ≤ G.lie with [G.lie, I] ⊆ I is ⊥ or G.lie. This is "nonabelian simple real Lie algebra" in the text.

  5. Casimir transport [S]. frobInner (Colors.lean:24–35) is the local instance ⟪x,y⟫ = Re tr(x y^*), unnormalised. colorIso (:52–54) is the standard orthonormal basis of G.Alg rescaled by √repDim; trace_color (:71–75) gives −Re tr(colorMat c · colorMat d) = repDim · ⟪c,d⟫, so colorMat of the standard basis is orthonormal for −r_G^{-1} Re tr(XY). ad c d = projectColor (colorMat c · colorMat d − colorMat d · colorMat c) (:136–150) and colorMat_ad (:152–154, via bracket_mem and colorMat_project_self, :103–104) show the projection acts as the identity on brackets, so ad is conjugate to the matrix commutator and casimir = −(Σ_i Tr(ad b_i ∘ ad b_i))/lieDim (:180–182) equals the text's C_𝔤 for that particular orthonormal basis. The text's basis independence is a (correct) strengthening not present in the source. Lean's / lieDim would be 0 if lieDim = 0; under Simple this does not occur.

  6. Positivity in Lean versus the text [S]. YM.Gauge.casimir_pos (Casimir.lean:160–172) bounds minusKilling x x > 0 for one non-central x and then needs trace_adjoint (:140–158), whose invariant_scalar step uses the ideal clause of Simple. The correspondence now says correctly that the manuscript's summed-commutator proof replaces this argument and uses only the nonabelian clause, and that comparison obtains positivity through slopeConstant_pos (:174–176).
