Findings and evidence

  • Branches. Bend := Option Bool (Slate/Pave.lean 23): none is the principal branch (Zn.Meld), and some c are the corrections Plint G n c built from Toca c (Margin/Mallet.lean 15–16). Toca true is \(\tfrac{1}{4} \sum\) of the diagonal pair labels on the diagonal; Toca false is the off-diagonal pair sum. These are the manuscript's \(J^+\) and \(J^-\). The manuscript's \(\{0, -, +\}\) is {none, some false, some true}.

  • Coefficients. BornZ i = i.elim (-tribe) azure, with tribe = ![1,-1/4,1] (Slate/April.lean 26–27) and azure M = if M then ![0,1/4,0] else ![0,0,1] (Margin/Mallet.lean 14). This gives \(w^0 = (- 1, \tfrac{1}{4}, - 1)\), \(w^+ = (0, \tfrac{1}{4}, 0)\), \(w^- = (0, 0, 1)\).

  • Material tensor. materialB C t = material (Cells.standard C) (Fin.cons 0 (BornZ t)) (Pear.lean 50). material S w a b = fromPol S (stress G w a b), with fromPol = S.project ∘ coords (Push/STRESS_FLUX/Lift.lean 24, 147). stress is, on the diagonal, t 0 • unit + t 1 • Σ_i pair a i a i + t 2 • ΣΣ pair i j i j, and off the diagonal t 3 • Σ_i pair a i b i (Polynomial.lean 177–179). With t 0 = 0 this is \(\pi_0 \mathcal{S} (w) = M (w)\). pair_value reads \(\langle F_{ab}, F_{cd} \rangle\) with no extra factor, matching the manuscript's \(P_{ij, kl}\).

  • First proposition. chartB says Phase4 J V Z j (baron S X k) = inter (Moment4 … (Shine4 Z X k)) · for k = Stern V j, with inter f a b = ½(f a b + f b a) (Shelves/Tonic.lean 49).
