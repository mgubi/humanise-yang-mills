Same-data and choice issues checked

Ch9 author confirms that the selected low-order panel excludes incoming activity arrays (Scott D351). It can be fixed on the compact coupling band before incoming affine rays, so finite tests compare the same output map. Stage widths and masks remain fixed. Parameter tests may use the explicit algebraic local expansion on its larger signed-array domain; positivity is retained for the actual selected histories, not asserted for arbitrary extrapolated raw arrays.

Zero-terminal scripted histories have positive bare path density. After a transition, changing only the next coupling leaves the activity gas fixed and multiplies the density by a positive path exponential. This supplies the needed admissibility/positivity induction for scripted histories; arbitrary completed activity classes are not presumed physical.

The standard Wilson terminal bound needed for the fixed-scale convergence proof is only norm<=1/8. A previous stronger request for a terminal-map Lipschitz bound has been removed because it is unnecessary for the geometric truncation proof.

Review priorities / remaining joins

  1. Actual all-history quadratic cutoff convergence is now supplied by ch05:horizon-limit. Chapter10 invokes that stronger result, not the uniform bound alone. Common comparison is now a proposition and fixed-scale convergence is stated for the actual common construction. Coupling comparison weight renamed mathfrak b_m to avoid collision with support B_m.

  2. Independently review ch10:parameter-supplier against the actual Ch6 protected coordinate conventions: real-node compensation keeps physical fine reads fixed; local rather than whole-volume Gaussian dimension is essential. Full derivative budget and common forced coefficient majorants, rather than pointwise bounds, are consumed by contraction.

  3. Common-input cutoff comparison requires the positive precision bound and a shared protected chart at each fixed scale. The actual comparison is now made with all physical fine masks fixed (reference threshold and dictionary at fixed scale); no moving-threshold measure-zero argument is used. Uniform output derivative convergence uses one additional Gaussian/chart score derivative with incoming physical reads held fixed, so it does not require an extra incoming activity derivative even on equal-order plateaux. This reserve must be fixed before stage constants.

  4. Hilbert-encoded coefficient arrays need summable encoding weights on the canonical dictionary. The chapter explicitly warns against ignoring path multiplicity. A fixed deterministic linear curl/path placement can alternatively give a direct stronger exponential l1 bound, avoiding unsupported orthogonal projection bounds in l1.

  5. No analyticity in the endpoint has been inferred. One-variable series appear only after the strong finite-test inequalities are proved from local real estimates.
