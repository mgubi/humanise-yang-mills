Corrections sent to the chapter author

  1. Exact full-remainder norm. Define the graph remainder norm using the actual adjacent forced allowances: incoming forced mass is charged by kappa_f^-1, outgoing by kappa_c^-1, with kappa the square root of the corresponding forced allowance. Martin's three-port estimate is coefficient and remainder <= eta m/kappa_f for a forced insertion of unnormalized support mass m. Its input integral allowance remains 2m. The current statement about retaining half the suppression does not display this normalization, which is needed to match the graph contraction norm in Chapter12. This is an interface requiring an actual bound, not merely a notation change.

  2. Derivative and geometry margins. State the regular attenuation prerequisites: coarse derivative order at least max(2,d+1), fine spatial weight at least d, fine kernel derivative level at least d+2, and coarse period at least 100(1+B_c), with anchored support and adjacent radius comparison. The actual three-port grade condition is d+3 <= coarse kernel level. Primary extraction additionally uses one insertion derivative beyond each probe derivative, available from its fixed local section. This need not impose an extra derivative on arbitrary incoming equal-regularity activity arrays.

  3. Polynomial cancellation. The short-support Taylor argument needs the screened polynomial moment cancellation obtained from vanishing radial/holonomy tests through the same fixed centered lift. Martin polynomial-moment-attenuation.tex proves this via the filtered gauge/radial germ, polynomial surjection and partition chain rule. Specify this implication and its hypotheses, rather than treating vanishing radial tests as unrestricted Taylor vanishing. The large-support estimate also includes a polynomial-in-coupling factor multiplying exp(-B_c/2), which is harmless because B_c grows quadratically in log coupling; retain that fact.

  4. Continuity topology. The graph continuity paragraph refers only to finite path parameters, whereas the supplied actual Gaussian rows converge as countable cover coefficient arrays. State continuity under weighted l1 convergence of those canonical coefficients at a strict width reserve, and under convergence of incoming activity arrays in their common norms. Finite truncation, uniform reserved tails, then dominated convergence give the intended route. This is the continuity notion required by the fixed-level ultraviolet argument.

  5. Name the curvature response. In the tree covariance calculation J is the curvature response satisfying DW=JD', not automatically the raw two-form row T of Chapter5. Define, for example, J=H_(0,f)^-1 T H_(0,c) using the unmodified diagonal metrics. The modified actual metrics still define K,K' and agree with these on curls. The covariance identity itself is correct with this interpretation.
