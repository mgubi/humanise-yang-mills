Reusable method

This method suits any future terminology or notation pass over the monograph.

  1. Export both trees with git archive <rev> manuscript | tar -x -C <dir>.

  2. Tokenise each changed file. Align the old and new token sequences and count the substitutions:

import re, difflib

TOK = re.compile(r'\\[A-Za-z]+|[A-Za-z]+|\d+(?:\.\d+)?|\s+|.')

ta, tb = TOK.findall(old_text), TOK.findall(new_text)

for op, i1, i2, j1, j2 in difflib.SequenceMatcher(None, ta, tb, autojunk=False).get_opcodes():

if op != 'equal':

record(''.join(ta[i1:i2]).strip(), ''.join(tb[j1:j2]).strip())

Each run of the tokeniser over the 180 files takes about a minute. 3. Keep the hunks that touch digits, ^ _ < > = + / |, a binary minus or \le \ge \frac \sum \exp \log …, and read each one. For #477 this gave 108 hunks. 4. For each new symbol, compare per-file counts before and after the diff. When the new count is higher and the old count was nonzero, a pre-existing symbol may now have two meanings in one file. Check it. 5. Count whole-word occurrences of the old identifiers in the new tree, and read every file that now has both the old and the new name. 6. Compare the multisets of \label, \ref, \eqref and \cite keys. 7. Search both trees for a word repeated across whitespace, including line breaks. Keep the cases that are new in the diff.
