Consequently the WilsonReference build emits a warning that Challenge.lean:5:8 uses sorry.

This placeholder is not suppressed or counted as a proved theorem. The verifier uses the reference declaration only for the exact type comparison described above, checks that the reference import graph contains no implementation module, and replays the solution declaration from the implementation environment. Limits of the evidence

  • A transitive axiom report establishes which axiom constants occur in an elaborated proof term. It does not establish that a theorem's hypotheses or definitions capture the intended mathematics or physics.

  • Kernel replay checks the reachable closure, not the 150,151 project declarations classified as outside all 17 release roots by Usage.lean.

  • The supplementary scan detects direct sorryAx uses and axiom declarations in YM modules; it is not itself a transitive semantic audit of every unused declaration.

  • The result trusts Lean 4.32.0, its kernel and replay implementation, and the pinned external libraries. No independent proof assistant or second Lean implementation was used.

  • No native-computation axiom appeared in the endpoint closures. This excludes a Lean.ofReduceBool dependency in those reported terms, but it is not a general audit of every computation performed while building the archive.
